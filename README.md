# ⛪ Raio de Sol - Website Oficial

Este é o repositório do site oficial da **Raio de Sol**. O objetivo principal desta plataforma é centralizar a comunicação da igreja, permitindo a divulgação de horários de cultos, eventos e facilitando o engajamento dos membros através de inscrições para o voluntariado, além de contar com um painel administrativo para a gestão dessas informações.

---

## 🚀 Funcionalidades Principais

### 🌐 Área Pública (Membros e Visitantes)
* **Agenda de Cultos:** Exibição clara dos dias e horários dos cultos semanais.
* **Mural de Eventos:** Divulgação de conferências, retiros, ações sociais e reuniões especiais.
* **Formulário de Voluntariado:** Espaço para que os membros escolham em quais ministérios (Mídia, Louvor, Infantil, Recepção, etc.) desejam servir, preenchendo seus dados de contato.

### 🔐 Área Administrativa (Gestão)
* **Autenticação Segura:** Painel protegido por login e senha para os líderes/administradores.
* **Controle de Voluntários:** * Visualização de todas as inscrições recebidas.
    * Filtragem de voluntários por ministério.
    * Alteração de status (Ex: *Pendente*, *Em Treinamento*, *Ativo*).
* **Gerenciador de Conteúdo:** Permite cadastrar, editar ou remover cultos e eventos diretamente pelo painel.
